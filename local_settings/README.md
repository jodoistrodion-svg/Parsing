# Локальные настройки бота

Вся ручная настройка теперь хранится **только здесь**, без `.env` и без `config.py`.

## 1) Токены

Создай файлы:

- `local_settings/tokens/telegram_token.txt`
- `local_settings/tokens/lzt_api_key.txt`

Просто вставь в каждый файл одно значение (без JSON, без `KEY=`).

## 2) Прочие настройки (не только токены)

Если нужно менять `OWNER_ID`, таймауты и другие параметры — скопируй `local_settings/settings.json.example` в `local_settings/settings.json` и измени нужные поля.

Если какого-то поля нет, бот использует встроенное значение по умолчанию.

## Приоритет источников

1. Переменные окружения (если задаются вручную)
2. `local_settings/settings.json`
3. Файлы токенов в `local_settings/tokens/`
4. Значения по умолчанию в коде
