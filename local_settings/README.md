# Локальные настройки

Этот каталог больше не обязателен.

Используй привычный формат без создания дополнительных файлов/папок:

1. Скопируй `.env.example` в `.env`
2. Впиши токены строками:
   - `API_TOKEN=...`
   - `LZT_API_KEY=...`

При необходимости можно задать токены и параметры через переменные окружения или в `config.py`.
